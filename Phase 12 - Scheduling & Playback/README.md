# Phase 12 — Scheduling & Playback

This phase adds the playback scheduling workflow.

Files map to the project-relative paths:
- src/pages/SchedulePage.tsx
- src/App.tsx

Features:
- List scheduled playback entries.
- Schedule either a campaign or an audio asset.
- Select an audio zone.
- Set start and optional end time.
- Configure one-time, daily, or weekly recurrence.
- Delete a schedule entry.
- Role-aware access for owner, marketing, and operations users.
